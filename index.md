# Coffee Time Backup

Coffee Time Backup is Brent Coggan's personal backup integration
for a privately hosted coffee-tracking application.

The integration uses rclone on a private Ubuntu server to back up
application database archives, configuration, certificates, and
coffee photographs to the owner's Google Drive.

This integration is for the owner's personal use only.
It is not offered as a public service.

Google Drive access is used to upload backups, compare existing
backup files, and remove expired backups according to the
configured retention policy.
